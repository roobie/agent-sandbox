New sandbox:stop implementation:

```toml
[tasks."sandbox:stop"]
description = "Stop and remove a named sandbox container (shows filesystem and workspace diffs)"
usage = '''
flag "--name -n <name>" help="Sandbox instance name to stop" default="default"
'''
run = """
NAME="${usage_name:-default}"
CONTAINER="agent-sandbox-${NAME}"

echo ""
echo "=== Container filesystem changes ==="
echo "(A=Added, C=Changed, D=Deleted)"
docker diff "${CONTAINER}" 2>/dev/null || echo "(no changes or container not found)"

echo ""
echo "=== Workspace changes ==="
WORKSPACE=$(docker inspect "${CONTAINER}" \
  --format '{{ range .Mounts }}{{ if eq .Destination "/workspace" }}{{ .Source }}{{ end }}{{ end }}' 2>/dev/null || echo "")
if [ -n "$WORKSPACE" ] && [ -d "$WORKSPACE" ]; then
  git -C "$WORKSPACE" diff --stat 2>/dev/null || echo "(workspace is not a git repo or no changes)"
else
  echo "(could not determine workspace path)"
fi

echo ""
docker stop "${CONTAINER}"
docker rm "${CONTAINER}"
echo "Sandbox ${CONTAINER} stopped"
"""
```

Key implementation details:
- `docker diff` runs BEFORE `docker stop` (container must be running for diff to work)
- `docker inspect --format` with Go template extracts the /workspace mount source path dynamically (no need to pass --workspace arg to stop)
- Section headers use "===" format per user decision in CONTEXT.md
- Legend line "(A=Added, C=Changed, D=Deleted)" documents docker diff output codes (Docker uses C not M)
- Graceful fallbacks: `|| echo "(no changes...)"` for missing containers, `|| echo "(workspace is not a git repo...)"` for non-git workspaces
