  <action>
Run the following sequence of commands. Record all output. Do not proceed if an early step fails — diagnose and fix before continuing.

**Step 1: Validate compose YAML**
```bash
docker compose config > /dev/null && echo "COMPOSE YAML OK"
```

**Step 2: Build images**
```bash
mise run sandbox:build
```
Expected: base and claude images build successfully. The `mise install --system` steps will take several minutes (downloading runtimes). If a download fails with a proxy error, the allowlist is missing a domain — add it to config/allowlist.txt and retry.

**Step 3: Start proxy**
```bash
mise run proxy:start
```
Expected: proxy container starts and reaches healthy state.

**Step 4: Start a sandbox and run version checks**
```bash
mise run sandbox:run --name verify-01 --workspace .
sleep 3

# Check all runtime versions
docker exec agent-sandbox-verify-01 bash -c "
node --version && \
python3 --version && \
go version && \
rustc --version && \
bun --version && \
uv --version && \
rust-analyzer --version && \
pyright --version && \
typescript-language-server --version
"
```
Record actual output. All commands must succeed (exit 0). Any "command not found" means the system install or PATH wiring failed.

**Step 5: Verify npm routes through proxy**
```bash
docker exec agent-sandbox-verify-01 bash -c "npm install --prefix /tmp lodash 2>&1 | tail -5"

# Check proxy access log for npm traffic
docker logs agent-sandbox-proxy 2>&1 | grep -i "npmjs" | tail -5
```
Expected: Squid access log shows entries with registry.npmjs.org or similar.

**Step 6: Verify proxy config files are present in container**
```bash
docker exec agent-sandbox-verify-01 bash -c "
cat /home/dev/.npmrc && \
git config --global http.proxy && \
cat /etc/cargo/config.toml
"
```
Expected: .npmrc has proxy lines, git config shows http://proxy:3128, cargo config has proxy setting.

**Step 7: Test multi-instance — start a second sandbox**
```bash
mise run sandbox:run --name verify-02 --workspace /tmp
docker ps --filter "name=agent-sandbox-verify" --format "table {{.Names}}\t{{.Status}}"
```
Expected: Both agent-sandbox-verify-01 and agent-sandbox-verify-02 appear as running.

**Step 8: Test cache persistence**
```bash
# Stop sandbox-01 and restart it
mise run sandbox:stop --name verify-01
mise run sandbox:run --name verify-01 --workspace .
sleep 3

# Second npm install should be cache hit (no network traffic, or very fast)
time docker exec agent-sandbox-verify-01 bash -c "npm install --prefer-offline --prefix /tmp2 lodash 2>&1 | tail -3"
```

**Step 9: Cleanup**
```bash
mise run sandbox:stop --name verify-01
mise run sandbox:stop --name verify-02
```

Record: All command outputs, any failures encountered and their resolutions.
