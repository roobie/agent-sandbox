images/proxy/Dockerfile — write this exactly:

    FROM debian:bookworm-slim

    RUN apt-get update && \
        apt-get install -y --no-install-recommends squid curl && \
        apt-get clean && rm -rf /var/lib/apt/lists/*

    # Build-time assertion: Debian bookworm squid package must include --with-openssl
    # (required for ssl_bump peek/splice directives in squid.conf)
    RUN squid -v 2>&1 | grep -q "with-openssl" || (echo "ERROR: squid missing --with-openssl" && exit 1)

    COPY squid.conf /etc/squid/squid.conf
    COPY allowlist.txt /etc/squid/allowlist.txt

    RUN chmod 644 /etc/squid/squid.conf /etc/squid/allowlist.txt

    EXPOSE 3128

    # -N: foreground mode so Docker captures PID 1 and logs
    # Logs route to stdout/stderr via access_log and cache_log in squid.conf
    CMD ["squid", "-N", "-f", "/etc/squid/squid.conf"]

images/proxy/squid.conf — write this exactly:

    # Squid forward proxy for agent-sandbox
    # SNI peek/splice: reads TLS ClientHello SNI field to verify destination hostname
    # before splicing the tunnel. No TLS decryption. No CA cert. No pinning breakage.
    # Reference: https://wiki.squid-cache.org/Features/SslBump

    http_port 3128

    # SNI peek/splice (requires --with-openssl — asserted in Dockerfile)
    ssl_bump peek all
    ssl_bump splice all

    # ACL definitions
    acl Safe_ports port 80
    acl Safe_ports port 443
    acl CONNECT method CONNECT
    acl SSL_ports port 443
    acl allowed_domains dstdomain "/etc/squid/allowlist.txt"

    # ACL enforcement — evaluated top to bottom, first match wins
    http_access deny !Safe_ports
    http_access deny CONNECT !SSL_ports
    http_access allow allowed_domains
    http_access deny all

    # Logging to stdout/stderr for docker logs
    access_log stdio:/dev/stdout
    cache_log stdio:/dev/stderr

    # Disable caching: freshness over performance for sandbox use
    cache deny all

Do NOT add ports: binding for proxy in docker-compose.yml. Port 3128 is reachable only within Docker networks. Compose wiring is Plan 03.
