# Quick Task 260324-61b: Add --claude-config flag to sandbox:run Summary

**One-liner:** Added `--claude-config / -c` boolean flag to `sandbox:run` that conditionally bind-mounts host `$HOME/.claude` readonly at `/home/dev/.host-claude` inside the container.

## What Was Done

Added a `--claude-config` (`-c`) boolean flag to the `sandbox:run` mise task so users can optionally expose their host Claude configuration (CLAUDE.md, settings.json, etc.) to the sandbox agent without allowing writes.

The mount target is `/home/dev/.host-claude` — deliberately separate from `/home/dev/.claude` which is already a named volume (`claude-state`) used for container-local Claude state. This avoids any volume conflicts.

## Changes

### mise.toml

- Added `flag "--claude-config -c"` to the `sandbox:run` usage block
- Added conditional block after variable assignments that sets `CLAUDE_MOUNT` when flag is passed and `$HOME/.claude` directory exists on host; prints a warning and leaves `CLAUDE_MOUNT` empty if directory is absent
- Inserted `${CLAUDE_MOUNT} \` into the `docker run` command after the go-cache volume line — empty variable is a no-op continuation, populated variable adds the `--volume` flag

### docker-compose.yml

- Replaced the two individual file mount comment lines (`CLAUDE.md` and `settings.json`) with a single directory mount comment line showing the directory-level pattern: `${HOME}/.claude:/home/dev/.host-claude:ro`
